# Reef Runner

A Temple Run-style 3D endless runner that runs in the browser (HTML + Three.js, no build step).

You play **Marlo**, a young explorer in a teal bandana, chased across ruined stone paths by the **Tide Colossus**, a giant coral-covered stone golem.

## Run it
Open `index.html` in Chrome (internet needed once for the Three.js CDN), or use the Live Server extension in VS Code.

## Controls
- Left / Right or A / D: change lane
- Up / W / Space: jump
- Down / S: slide
- P: pause
- Touch: swipe left, right, up, down

## Features
- 3 lanes, jump and slide, logs / hanging beams / stone blocks to dodge
- Coins, magnet and shield power-ups
- Speed ramps up with distance, the Colossus closes in when you stumble
- Procedural sound effects, best distance saved locally
